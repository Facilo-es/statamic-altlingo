# Security

Please report security issues privately, never in a public issue:

- Email **support@facilo.es** with "Security" in the subject, or
- Use GitHub's private vulnerability reporting on this repository (Security → Report a vulnerability).

Include the version, what you found and how to reproduce it. We confirm receipt within 2 working days and aim to release a fix within 14 days, or sooner for a flaw that is actively exploited. We credit reporters in the changelog unless you'd rather not be named.

Supported versions: the latest 1.x release.
